RubickShop - Интернет-магазин гаджетов 2026

Полнофункциональный интернет-магазин электроники на HTML5, CSS3, JavaScript.

Структура файлов:
index.html - Главная страница с каталогом
cart.html - Страница корзины покупок
feedback.html - Форма обратной связи
style.css - Единые стили всех страниц
script.js - Логика каталога, корзины, модальных окон

Основная функциональность:

Главная страница (index.html):
Рекламный баннер с акцией "3000 бонусов при первом заказе"
Фиксированная зеленая шапка с логотипом, навигацией, соцсетями, корзиной
Боковая панель фильтров:
Бренды: Samsung, Huawei, Sony
Категории: смартфоны, ноутбуки, наушники, планшеты
Слайдер цены (0-200000 ₽)
Кнопка "Сбросить"
Каталог товаров: 8 карточек фиксированного размера 220x320px
Модальное окно товара с фото, характеристиками, ценами, кэшбэком

Корзина покупок (cart.html):
Список товаров с изображением, названием, ценами
Управление количеством (+/-)
Кнопки удаления товаров
Итоговая сумма заказа
Кнопка "Оформить заказ"

Особенности реализации:

Дизайн и верстка:
CSS Grid: repeat(auto-fill, minmax(220px, 1fr))
Фиксированный баннер: z-index 1000, sticky
Фиксированная шапка: z-index 100, top после баннера
Карточки товаров: height 320px, object-fit: contain
Hover-эффекты: translateY(-5px), scale изображений
Анимации: fadeInUp для карточек, slideDown для баннера

JavaScript функционал:
Данные товаров в массиве products (8 объектов)
Фильтрация по бренду/категории/цене
Корзина с localStorage (cart массив)
Модальные окна с backdrop-filter blur
Обработка ошибок изображений (placeholder)
Кнопка "Добавлено!" с обратным отсчетом
Закрытие модалки по ESC и клику вне


Технические детали:
Цены с toLocaleString('ru-RU') для пробелов
Скидка: Math.round((old-new)/old * 100)
onerror для изображений
Плавная прокрутка: scroll-behavior: smooth
Фокус-стили для доступности

Запуск:
1. Сохранить все файлы в папку
2. Открыть index.html в браузере
3. Тестировать фильтры, корзину, модалки
